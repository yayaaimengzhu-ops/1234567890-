## 怎么用

- 用浏览器直接打开 HTML 文件，不需要联网。两个文件放在同一个文件夹里，大纲和教案之间的链接才能互相跳转。
- 教案里填写的内容自动保存在本机浏览器里，换浏览器或清理缓存会丢。要发给别人或长期保存，点右下角"导出已填写版"；要贴进微信或文档，点"复制全部填写"。
- 打印用浏览器的打印（Ctrl + P，Mac 用 ⌘ + P），没填的框会留白，可以手写。
