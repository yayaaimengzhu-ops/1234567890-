## 怎么用

- 用浏览器直接打开 HTML 文件，不需要联网。几个文件放在同一个文件夹里，大纲、教案和各站诊断表之间的链接才能互相跳转。
- 教案和诊断表里填写的内容自动保存在本机浏览器里，换浏览器或清理缓存会丢。要发给别人或长期保存，点右下角"导出已填写版"；要贴进微信或文档，点"复制全部填写"。
- 打印用浏览器的打印（Ctrl + P，Mac 用 ⌘ + P），没填的框会留白，可以手写。
- 要改表格的内容和样式，改 `word/` 里的 Word 版。Word 版改过之后，网页版不会跟着变；两边都要改的，按 `tools/worksheets/build_all.py` 开头的说明重新生成。
- 表里的参考值、评级、示例场景和"建议口径"是常见判断，开课前由讲师按本地行情校准；涉及法律和税务的内容只讲风险意识，协议模板用之前要经过律师审核。
