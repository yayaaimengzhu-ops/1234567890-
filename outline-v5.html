核心主张

手上有什么资源，就 all in 什么路。

三百六十行，行行出状元。短视频是现在的主流，但不是唯一。有人脉走关系路径，有预算走付费路径，有门店有腿脚走本地路径，会写文案走平台路径——只要资源是真的，哪条路都能出单。这门课把五条路都讲到能独立跑通，然后让你选一条 all in。

课程解决四件事：人从哪来、货是真是假、怎么把人聊到愿意卖、收进来的货怎么安全变成钱。

三条原则贯穿全课。第一，按资源选路，选定就 all in。第二，按能力依赖顺序讲——先会看货，才会算价；先会算价，才守得住价。第三，先避损，再谈赚——鉴定和估价的目标不是把你变成鉴定师，是把损失降到最低，而做到这件事最快的方式是借力，不是硬扛。

v5 把第三条原则落到了每一站：风控不再单独成站，拆进每一站的末尾。在哪一步做事，就在哪一步学这一步最容易犯的错、犯了最坏会怎样、该怎么防。

v4 → v5 改了什么

五处。前两处是结构层的，后三处是落地层的。

  1. 风控拆进每一站，原第八站取消每一站末尾新增"本站风控"：这一站最常见的错误做法、最坏会怎样、怎么防。原第八站的十一节按"风险在哪一步发生，就挂在哪一步"逐条迁入——货品来源挂到成交，出镜人协议挂到获客，上游协议挂到鉴定，三本账挂到交易闭环，一条不少，去向见附录的迁移对照表。v4 把风控放在成交之后、出货之前，是在"放太早学员挂不住、放太晚制度来不及"之间取中；拆开之后这个两难自然消失，每条风控都有自己的挂靠对象。
  2. 估价、报价、成交、出货、复购合并为第六站"交易闭环"成交完就直接出货，拆成四站讲，学员会把"收"和"出"当成两件事。合并后一件货从估价讲到回款、再讲到卖家回头，一站走完。v4 里为了弥补"渠道在第九站才讲"而前置的出货预判三问不再需要打补丁：出口知识放到估价环节的开头，三问变成整站的总开关。
  3. 私域沉淀并入第三站原 2.7 私域沉淀移到第三站开头，第三站改为"私域承接"。私域号归属、防封、备份，以及员工带走客户的风险，放在这里一起讲。
  4. 课前风险自测与结营风控总复盘前后呼应课前做一份十题自测当基线，结营同一份题再做一遍。结营新增风控总复盘，把六站的红线、协议、应急卡汇成一套带走。
  5. 每站加"找错"练习，出课标准加风控项每站课堂动作里加一轮风险场景判断，出课标准里至少有一项风控产出：止损线、协议、存证、应急卡。认知升级从八个误解加到九个，第九个是"以为风控是做大以后的事"。
v3 → v4 改了什么（存档）
  1. 获客改为五条平行路径，all in 逻辑提到定位主张关系 / 内容 / 付费 / 本地 / 平台，五条路各自独立成路，每条配启动动作、见效周期、天花板、30 天落地表。短视频只是内容路径里的一支，不再是默认答案。第二站的出课标准按路径分列——让一个决定 all in 地推的人交"一条已发布的视频"，这个要求本身就是错的。
  2. 鉴定站重心从"教你判"改为"教你不亏"外部兜底体系（上游兜底、机构送检、同行复核、结构性规避）从末尾提到 5.2，成为这一站的第一根支柱。因为对多数人来说，借力兜底才是主路，自己判是长期能力。同时新增决策表：什么货自己判、什么送检、什么找上游、什么直接转撮合。
  3. 新增认知升级模块（1.2）课程要打开认知，不只是给动作。八个常见误解逐个拆——不会鉴定就不能入行、必须自己出镜、必须有店有钱、必须做短视频、收得越多赚得越多。这一节是整门课的认知锚。
  4. 出镜从一行扩成一整节不出镜的四种做法 + 找人出镜的完整方法：找谁、怎么谈、怎么分工、怎么让不懂行的人把内容讲对、协议怎么签、人走了账号怎么办。出镜人风险同步进第八站风控。
  5. 付费投流压缩从八节收成一节。正课只讲什么阶段该投、投什么目标、ROI 怎么算、什么时候停，各平台的具体操作走分册手册。
  6. 资源盘点加真实性校验"我人脉广"是自我感觉，得转成可数的。All in 一条真实存在的路是对的，all in 一条自以为存在的路，比分散做更危险。

一

定位把认知打开，把手上的牌盘清楚

这一站做三件事：打开认知——让学员知道这行远不止他以为的那一种做法；盘清资源——让他知道自己该 all in 哪条路；摊开风险地图——让他知道这门生意会在哪几处出事、每一处在哪一站拆。三件事做完，第二站的选路才有依据。

1.2 认知升级：你以为的，和实际的填表 1.2

九个误解，逐个拆

  • 以为不会鉴定就不能入行 —— 实际有三条路绕开：上游兜底、机构送检、撮合规避。会鉴定是加分项，不是入场券（第五站展开）
  • 以为必须自己出镜 —— 实际可以不露脸、可以找人出镜、可以做图文，也可以根本不走内容路径
  • 以为必须有店有钱 —— 实际零库存起步的三条路都不需要压资金
  • 以为短视频是唯一的路 —— 实际关系、付费、本地、平台四条路都能独立出单，看你手上有什么
  • 以为这行暴利 —— 实际毛利区间是多少、周转怎么吃掉毛利
  • 以为要做全品类 —— 实际先做透一个品类的人跑得最快
  • 以为收得越多赚得越多 —— 实际压货是这行最大的死因
  • 以为客户都想卖高价 —— 实际卖家的动机分四类，只有一类是价格敏感
  • 以为风控是做大以后的事 新增 —— 实际第一单就可能碰上赃物、调包、假转账截图，出一次事就可能直接出局。所以风控不单独成站，每一站都讲这一步会在哪里出事

这行真正的门槛在哪

  • 不是鉴定技术，是获客能力和风险意识
  • 赚钱的人在赚哪几种钱：差价、周转、信息差、渠道差、服务费
  • 你可能不知道的几条路：居间撮合、代收、导流分成、做渠道商、鉴定服务、寄卖代运营、给同行供货
这一节是整门课的认知锚。多数人卡在门口，不是因为不会做，是因为以为自己必须先成为某种人才能开始。把这九条拆开，剩下的五站才有人愿意听下去。

1.3 五种链路模式，分别适合什么人填表 1.3

  • 纯回收赚差价：压资金，单笔利润高，吃估价能力
  • 居间撮合：先谈好买家再收，零库存零压力，利润薄但适合起步
  • 寄卖代卖：不压钱，赚佣金，回款周期长
  • 鉴定服务收费：轻资产，靠专业变现
  • 门店零售：重资产，靠客流和溢价，回本慢
  • 组合打法：回收为主，撮合和寄卖做补充，大货吃不下就转撮合
  • 每种模式各自扛什么风险 风控：真假风险、压货风险、资金风险、纠纷风险分别落在谁身上——同一件货换一种模式，风险就换一个人扛

1.4 把这门生意的账算清楚填表 1.4

  • 单笔毛利怎么算：收价、出价、差价，再扣物流、鉴定费、平台手续费、退货损耗

  • 行业基准区间：各品类的参考成交率、参考客单毛利、参考复购次数

真实性校验：把形容词换成数字

  • "人脉广" → 能直接打电话不尴尬的有几个？其中和二奢人群重合的有几个？上次联系是什么时候？
  • "有行业关系" → 能直接约出来吃饭的有几家？谈过合作没有？
  • "有客户名单" → 名单上有多少人？多久没联系了？还认得你吗？
  • "有账号" → 真实粉丝多少？最近三条数据？还能不能发
  • "有预算" → 能亏掉不影响生活的是多少？
  • 校验后重新排序，圈出经得起数字检验的三张牌
这一节是整门课的分岔口，也是最容易自欺的一节。All in 一条真实存在的路是对的；all in 一条自以为存在的路，比分散做还危险。所以盘点必须走完校验，形容词一律换成可数的数字。

1.6 零库存起步路径与新手安全通道填表 1.6A · 1.6B

零库存怎么起步

  • 三条不压钱的路：居间撮合、代收、先谈好买家再收货

安全通道：风险敞口随能力递增

  • 第 1 阶段：只做撮合，或只碰有小票保卡的低价品类，一律走机构鉴定或上游兜底
  • 第 2 阶段：可自收，但单笔上限 X 元，判不准的一律送检或找同行复核
  • 第 3 阶段：放开品类和金额，按自己的判断收

  • 止损线：单笔最多亏多少、连续几单看走眼就必须停下来复盘

2.1 五条路径与 all in 逻辑填表 2.1A–B

路径全景

路径适合谁启动成本见效天花板稳定性最大的坑

怎么选

  • 把第一站校验过的三张牌摊开，对着上表选，牌在哪条路上，就走哪条路
  • 三个否决项：这条路你有没有时间、有没有钱、能不能坚持三个月
  • 选不出来怎么办：默认走关系路径起步，因为它最快见到第一单，第一单能救活很多人的信心
  • 把输得起放进去比 风控：同样有牌，选你输得起的那条——关系路径输的是人情，付费路径输的是钱，内容路径输的是时间

all in 是什么意思，不是什么意思

  • 是：第一个月 80% 的时间和预算压在这一条上，把它跑到有数据可分析
  • 不是：其他四条永不碰。承接、转化、私域这些公共动作，无论走哪条路都要做
  • 什么时候该加第二条路：第一条跑出稳定数据、且已经出现瓶颈信号
  • 什么时候该换路：三个可量化的止损口径，别拿"再坚持一下"骗自己
  • 为什么不要一上来五条全铺：每条路都有学习成本和冷启动期，五条同时冷启动等于五条都启动不了

2.3.4 出镜与出镜分工

不擅长出镜完全不影响做内容路径。四种做法，按自己的条件选。

  • 做法一 · 不露脸：货品特写 + 手部出镜 + 字幕配音，回收类内容天然适合
  • 做法二 · 图文：图文口播、笔记形式，小红书和视频号都吃得开
  • 做法三 · AI 分身：数字人的适用场景与明显短板，什么内容能用什么不能
  • 做法四 · 找人出镜：下面展开

找人出镜怎么做

  • 找谁：合伙人、配偶、亲戚、朋友、雇的兼职、专业口播，五种关系的稳定性和成本对比
  • 对方需要具备什么：不需要懂行，需要的是镜头感、配合度、稳定性——懂行的是你
  • 怎么谈：按条给钱、按月给钱、给业绩分成、给股份，各自适合什么关系，别一上来就谈股份
  • 分工怎么定：你出选题、脚本和专业判断，他出脸和表达；剪辑、发布、接私信各归谁
  • 怎么让不懂行的人把专业内容讲对：脚本颗粒度到什么程度、要不要提词器、拍前对稿、哪几句话一个字都不能改
  • 拍摄配合流程：一次拍几条、多久拍一次、怎么提高单次拍摄效率、卡壳了怎么办
  • 常见问题：对方拍着拍着不想拍了、要涨价、临时放鸽子、越拍越敷衍

出镜人风险与降依赖 风控迁自 8.3 · 8.8 · 8.11

  • 人设绑定风险：粉丝认人不认号，人走了账号就废
  • 账号、素材、粉丝的归属怎么约定，肖像使用怎么授权
  • 肖像使用授权：拍了的素材他走之后还能不能用
  • 出镜人合作协议：报酬、账号与素材归属、肖像授权、退出交接、竞业约定——本节给模板，开拍之前现场填
  • 中途涨价、要挟、消极配合怎么处理
  • 出镜人自己想单干了怎么办
  • 降依赖的四个做法：多人出镜、部分内容不露脸、账号定位偏内容不偏个人、同步把粉丝沉到私域
  • 真出问题了怎么换人：过渡期怎么发、怎么跟粉丝交代
  • 出镜人突然走人的第一小时：改密码、收回后台和收款权限、备份素材、定好对外口径

自己出镜的基本功（给愿意出镜的人）

  • 镜头感：语速、停顿、重音、眼神落点
  • 口条不好、方言重、不上镜，分别怎么补救

五

鉴定目标不是成为鉴定师，是把损失降到最低重点交付

这一站的命题是怎么让自己不亏，不是怎么显得专业。做到这件事有两条路：自己判，和借力判。对多数人来说，借力才是主路，自己判是长期能力。所以这一站先讲兜底，再讲判定，最后讲鉴定这件事本身会带来哪些风险。

5.1 三道防线填表 5.1

  • 第一道 · 结构性规避：根本不承担真假风险——撮合、寄卖、定金后验、验货后付
  • 第二道 · 借力判定：上游兜底、机构送检、同行复核、平台鉴定
  • 第三道 · 自己判定：L1 一眼假 → L2 常见款判定 → L3 边界识别
  • 三道防线的成本、时效和适用场景对比
  • 一单看走眼等于白干多少单 —— 用第一站的测算表算给学员看
  • 三道防线分别对应第一站安全通道的哪个阶段
这一站最重要的一句话：判不了的时候知道自己判不了，然后知道该找谁。这既保护学员，也保护课程——招生时讲清楚能力边界，后面不会有人拿"我学完还是看走眼了"来找你。

5.2 外部兜底体系填表 5.2A–C

上游兜底

  • 什么叫上游兜底：上游收你的货，同时替你承担判定责任
  • 上游是谁：大回收商、渠道商、B 端平台、批发档口、同行大户
  • 怎么找上游、第一次怎么开口、怎么从小单做到大单
  • 上游凭什么给你兜底：他赚什么、你让什么
  • 兜底的几种形式：先验后款、包退包换、代验代收、直接报价收
  • 成本核算：让出多少利润换兜底是合理的
  • 风险：上游压价、上游跑路、被上游挖走客户、被上游反向套价
  • 什么阶段该依赖上游、什么阶段该自己上
  • 上游合作协议 迁自 8.3：兜底范围、退换条件、结算方式、争议处理——逐条讲关键点和常见坑，现场填自己的信息
  • 上游压价与跑路的预警信号 迁自 8.10：结算越拖越长、兜底条件临时加码、开始打听你的客户
  • 上游跑路的第一小时 迁自 8.11：停止发货、清点在途货和未结款、固定聊天和转账证据

第三方鉴定机构

  • 得物、优奢易拍、中检、包大师：价格、时效、准确度、支持品类对比
  • 线上鉴定 vs 线下送检，各自适用什么场景
  • 出具报告的意义：对客户、对下游、对纠纷
  • 鉴定费谁出：怎么跟客户谈，怎么把它变成信任加分项
  • 机构也会看错：报告的责任边界在哪
  • 假鉴定报告 迁自 8.5：报告编号到机构官方渠道核验，不认截图，不认对方发来的链接

同行复核网络

  • 怎么建：找谁、怎么开口、给不给钱、怎么互惠
  • 什么货值得麻烦别人
  • 复核的时效问题：客户等不了怎么办
  • 复核时不暴露客户 风控：图片去掉能认出客户的信息，不说客户是谁、在哪

结构性规避

  • 居间撮合：让买家自己去验，你只赚服务费
  • 寄卖代卖：不买断就不承担真假风险
  • 走平台交易，让平台承担鉴定责任
  • 先付定金后验货、验货后付款的具体操作

决策表：这货该怎么处理

6.2 估价：从出口倒推收价 原第六站 6.1–6.5 · 原 9.1 · 9.4填表 6.2A–F

和鉴定一样，估价也有借力的路。估不准不等于不能做——上游报价、同行群、平台估价都能兜底。但长期一直用别人的价，自己永远建不起判断，所以两条线并讲。先讲出口，因为收价是从出货价倒推出来的。

6.2.1 出口先行：出货渠道全景

  • 上游与同行直出：同行群、批发市场、档口、上游大户，速度最快价格最低
  • 得物：寄卖与回收两条路、鉴别流程、手续费、账期、什么货适合走
  • 平台寄卖：红布林、只二、心上、胖虎 —— 门槛、佣金、回款周期对比
  • 直播间寄卖：怎么找主播、怎么分成、什么货在直播间走得动
  • B 端平台：批量出货怎么走、报价怎么谈
  • 自己零售：闲鱼、转转、朋友圈、小红书、抖音小店、门店，利润最高但最慢
  • 拍卖：线上拍卖与拍卖行，什么货值得走
  • 其他出口：出口外贸、翻新改色后再售、拆件卖零配

6.2.2 估价的外部依托

  • 上游报价倒推：直接问上游这货能收多少，减掉自己的利润就是报价上限
  • 同行报价群：怎么问、怎么甄别水分、怎么不暴露自己的客户
  • 平台估价：各回收平台的在线估价工具，准不准、怎么用
  • B 端平台批量报价：适合什么货
  • 什么时候该用别人的价、什么时候必须自己算
  • 长期风险：一直依赖外部报价，利润会被上游锁死，且永远建不起自己的判断
  • 从依赖到独立的过渡路径：先对答案，再自己报，最后只在疑难件上问

6.2.3 估价的三个变量

  • 公价与市场行情价的区别
  • 成色分级：全新 / 99 新 / 95 新 / 九成 / 八成，各级的判定标准（接第五站）
  • 配件齐全度：包装、票据、保卡、防尘袋、多余扣，分别值多少钱
  • 瑕疵怎么折价：磨损、变形、掉色、异味、修复痕迹

6.2.4 行情从哪来

  • 得物、红布林、只二、心上、胖虎的成交价怎么看，看的是挂价还是成交价
  • 二奢查价小程序与工具
  • 拍卖行与批发档口的价格参考
  • 建自己的行情表，每周更新一次
  • 行情波动的信号：什么时候该压价、什么时候该抢货

6.2.5 折价逻辑与到手价倒推

  • 从零售价到回收价，中间扣掉的每一层分别是什么
  • 品类系数、成色系数、配件系数、稀缺款溢价
  • 流通速度直接影响报价：好出的货可以让利抢单，难出的货必须压价
  • 留多少利润给自己，留多少空间给下游渠道
  • 走兜底渠道的货，成本里要多算哪几项
  • 出货定价怎么定，留多少议价空间
  • 各渠道的实际到手价怎么算：扣完手续费、物流、鉴定费之后还剩多少
  • 同一件货在不同渠道的到手价对比实操

6.5 出货：收得进来，更要卖得出去 原第九站 · 原 8.5 · 8.9 · 8.10填表 6.5A–E

6.5.1 什么货走什么渠道

  • 真假存疑的货怎么处理，绝对不能往哪里出

人群路径导航

凡是有获客需求、或有二手成交意向的人都能学。开课第一天发这张表，帮学员对上自己该 all in 哪条路。

有人脉、有职业身份、有行业关系、有老客户
→ 关系路径。第一站的资源盘点是你最重要的一节课。你的第一单大概率来自现有关系，不是平台。别把现成的牌扔了去从零起号。第五站重点听 5.2 兜底体系——你有客户但缺专业，正好用兜底补上。熟人的货照样走验货流程。
没资源，但愿意出镜、有时间产出
→ 内容路径。天花板最高但最慢，前两周没反馈是正常的。第五站和第六站的估价、报价环节必须扎实，因为你的信任全靠专业度建立，没有熟人背书兜底。2.3.8 的内容合规是你的生命线。
没资源、也不愿出镜，但身边有人能出镜
→ 内容路径，重点听 2.3.4 出镜分工和出镜人风险。分工和协议先谈清楚，再开始拍。
有预算、想快
→ 付费路径。但前提是承接和转化已经跑通，否则投进去的钱全漏掉。第三、四站要先啃，第二站的付费部分反而简单。
有门店、有本地资源、跑得动腿
→ 本地路径。地图、点评、地推是你的主场，区域做透了比什么都稳。短视频做同城内容作为补充即可。上门收货多，第六站 6.4.3 的安全流程必听。
什么都没有，只有时间和耐心
→ 平台路径。闲鱼零成本、不用露脸、不用人脉，是资源最少的人唯一能立刻开始的一条路。先把 2.6 的防骗清单背熟。
已入行缺客源
用 6.6.4 的六个数找出自己掉率最高的环节，回去先补那一站。第二站按自己现有资源重新选一次路——很多人卡住是因为选错了路，不是不够努力。
已入行怕看走眼
第五站的 5.1 三道防线和 5.2 兜底体系是你来的理由，每站末尾的风控清单必听，第六站成交环节的来源核查与存证（6.4.4–6.4.6）是重中之重。回去先把上游、复核关系和存证规范建起来，再谈扩量。
老学员回炉
开课前做三个自测：第五站的实物盲测与决策表判断、第六站估价环节的盲报、第六站出货环节的分渠道。哪一项掉分最多，时间就压在哪一站。再对照课前风险自测，看自己的风控短板在哪一站。
带团队的学员
正课按单兵内容学，用人风险必听：1.9 合伙、2.3.4 出镜人、3.1 私域号归属、5.12 鉴定责任、6.7.2 员工与内控。团队复制走结营后的选修加餐。

与技术课的衔接

  • 能力切分：本课交付三道防线的全部内容——结构性规避、外部兜底、以及自己判定的 L1 一眼假 / L2 常见款 / L3 边界识别。技术课接 L3 之后：疑难件、全品类深度、鉴定服务变现。
  • 盲测考什么：考动线走得对不对、判断敢不敢下、边界认得清不清、决策表用得准不准。不是考记住了多少细节点。
  • 招生页必须写清：这门课让你会什么（五条获客路径、承接转化、避损体系与常见款鉴定、估价报价、风险防控、出货复购），不会什么（疑难件与全品类深度鉴定）。含糊过去的话，退款和差评的风险都在这里。
  • 样本库要求：第五站的实物盲测需要真货与不同档次的高仿样本。品类覆盖和高仿档次直接决定这一站的交付质量，是筹备期的第一优先级。
  • 兜底资源要求：5.2 要交付的不只是方法，还有可对接的上游和机构清单。这部分是你的独家资源，也是这门课最难被抄走的地方。
