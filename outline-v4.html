核心主张

手上有什么资源，就 all in 什么路。

三百六十行，行行出状元。短视频是现在的主流，但不是唯一。有人脉走关系路径，有预算走付费路径，有门店有腿脚走本地路径，会写文案走平台路径——只要资源是真的，哪条路都能出单。这门课把五条路都讲到能独立跑通，然后让你选一条 all in。

课程解决四件事：人从哪来、货是真是假、怎么把人聊到愿意卖、收进来的货怎么安全变成钱。

三条原则贯穿全课。第一，按资源选路，选定就 all in。第二，按能力依赖顺序讲——先会看货，才会算价；先会算价，才守得住价。第三，先避损，再谈赚——鉴定和估价的目标不是把你变成鉴定师，是把损失降到最低，而做到这件事最快的方式是借力，不是硬扛。

课前

准备包带着东西来上课

开课前一周发出，第一天签到时检查。目的是让学员进教室时手上已经有素材，第一站的资源盘点当场就能填、能验真。

  • 按资源盘点表把通讯录、微信好友、已加的群预填一遍，要填可数的数字，不填形容词

  • 列出能直接联系上的行业相关的人：金店、典当、修表、洗护、婚庆、美容、房产、二手车、保险

0.2 课前发放资料

  • 各品牌基础资料与款式图册（第五站的前置阅读）
  • 行业词汇表与黑话对照
  • 行业参考书单与阅读顺序
  • 资源盘点表、单店测算表空白版

一

定位把认知打开，把手上的牌盘清楚

这一站做两件事：打开认知——让学员知道这行远不止他以为的那一种做法；盘清资源——让他知道自己该 all in 哪条路。两件事做完，第二站的选路才有依据。

1.1 行业全景：货从哪来，钱从哪赚

  • 二手奢侈品行业现状：市场规模、增速、为什么这两年能做
  • 一条完整的货流：C 端卖家 → 回收商 → 渠道 / 同行 / 平台 → C 端买家
  • 行业角色全景：回收商、鉴定师、渠道商、寄卖平台、批发档口、拍卖行、维修保养、清洗改色、上游大户
  • 每个角色赚什么钱、门槛多高、天花板在哪
  • 我们站在回收端：靠差价和周转赚钱
  • 行业的季节性与周期：什么时候货多、什么时候好出

1.2 认知升级：你以为的，和实际的 新增

八个误解，逐个拆

  • 以为不会鉴定就不能入行 —— 实际有三条路绕开：上游兜底、机构送检、撮合规避。会鉴定是加分项，不是入场券（第五站展开）
  • 以为必须自己出镜 —— 实际可以不露脸、可以找人出镜、可以做图文，也可以根本不走内容路径
  • 以为必须有店有钱 —— 实际零库存起步的三条路都不需要压资金
  • 以为短视频是唯一的路 —— 实际关系、付费、本地、平台四条路都能独立出单，看你手上有什么
  • 以为这行暴利 —— 实际毛利区间是多少、周转怎么吃掉毛利
  • 以为要做全品类 —— 实际先做透一个品类的人跑得最快
  • 以为收得越多赚得越多 —— 实际压货是这行最大的死因
  • 以为客户都想卖高价 —— 实际卖家的动机分四类，只有一类是价格敏感

这行真正的门槛在哪

  • 不是鉴定技术，是获客能力和风险意识
  • 赚钱的人在赚哪几种钱：差价、周转、信息差、渠道差、服务费
  • 你可能不知道的几条路：居间撮合、代收、导流分成、做渠道商、鉴定服务、寄卖代运营、给同行供货
这一节是整门课的认知锚。多数人卡在门口，不是因为不会做，是因为以为自己必须先成为某种人才能开始。把这八条拆开，剩下的九站才有人愿意听下去。

1.3 五种链路模式，分别适合什么人

  • 纯回收赚差价：压资金，单笔利润高，吃估价能力
  • 居间撮合：先谈好买家再收，零库存零压力，利润薄但适合起步
  • 寄卖代卖：不压钱，赚佣金，回款周期长
  • 鉴定服务收费：轻资产，靠专业变现
  • 门店零售：重资产，靠客流和溢价，回本慢
  • 组合打法：回收为主，撮合和寄卖做补充，大货吃不下就转撮合

1.4 把这门生意的账算清楚

  • 单笔毛利怎么算：收价、出价、差价，再扣物流、鉴定费、平台手续费、退货损耗
  • 各品类的真实毛利区间
  • 行业基准区间：各品类的参考成交率、参考客单毛利、参考复购次数
  • 一个客户值多少钱：成交率 × 客单毛利 × 复购次数
  • 月目标倒推：想赚多少 → 成交几单 → 谈几个客户 → 加几个微信 → 每天做几个动作
  • 动作量按路径换算：走内容路径是发几条视频，走关系路径是打几个电话，走本地路径是跑几家店，走付费路径是花多少钱
  • 周转率比毛利率更重要
  • 多少钱起步、第一个月这笔钱怎么花

课堂动作

  • 现场填测算表，当场念出自己每天要完成的动作量
基准数据必须先备好，否则新手填出来的是想象。允许按自己选的品类取值，当场标注"这是假设，结营前校准"。

1.5 我手上已经有什么 —— 资源盘点

八类底牌，逐项盘

  • 人脉存量：通讯录、微信好友数、已加的群、老同学老同事、亲戚邻居
  • 职业与身份资产：现在或过去的职业带来的信任度，能接触到什么人群
  • 线上存量资产：已有账号、粉丝、社群、公众号、闲鱼号、朋友圈体量
  • 线下存量资产：门店、客流、场地、库存、车
  • 行业关系：金店、典当行、修表店、洗护店、名品折扣、美容院、会所、房产中介、保险、二手车、婚庆、律师、财务
  • 客户名单：做过其他生意积累的客户，哪些人群和二奢重合
  • 地缘与圈层：本地社群、商会、老乡会、车友会、宝妈群、业主群、健身房、宠物群、兴趣圈
  • 时间、资金与配合资源：全职兼职、每天几小时、启动资金、身边有没有能帮你出镜的人

真实性校验：把形容词换成数字 新增

  • "人脉广" → 能直接打电话不尴尬的有几个？其中和二奢人群重合的有几个？上次联系是什么时候？
  • "有行业关系" → 能直接约出来吃饭的有几家？谈过合作没有？
  • "有客户名单" → 名单上有多少人？多久没联系了？还认得你吗？
  • "有账号" → 真实粉丝多少？最近三条数据？还能不能发
  • "有预算" → 能亏掉不影响生活的是多少？
  • 校验后重新排序，圈出经得起数字检验的三张牌
这一节是整门课的分岔口，也是最容易自欺的一节。All in 一条真实存在的路是对的；all in 一条自以为存在的路，比分散做还危险。所以盘点必须走完校验，形容词一律换成可数的数字。

1.6 零库存起步路径与新手安全通道

零库存怎么起步

  • 三条不压钱的路：居间撮合、代收、先谈好买家再收货
  • 第一个月只做撮合能赚到什么、赚不到什么
  • 什么时候可以开始压第一笔货

安全通道：风险敞口随能力递增

  • 第 1 阶段：只做撮合，或只碰有小票保卡的低价品类，一律走机构鉴定或上游兜底
  • 第 2 阶段：可自收，但单笔上限 X 元，判不准的一律送检或找同行复核
  • 第 3 阶段：放开品类和金额，按自己的判断收
  • 三个阶段分别对应第五站鉴定能力的哪一级
  • 止损线：单笔最多亏多少、连续几单看走眼就必须停下来复盘

1.7 给自己定位（暂定版）

  • 品类怎么选：包 / 表 / 黄金 / 珠宝 / 服饰 / 潮牌 / 数码 —— 难度、利润、周转、货源量四项对比
  • 新手从哪个品类切入最不容易死
  • 有店还是无店、全职还是兼职
  • 人设方向：鉴定师、回收老板、本地上门服务，选一个别混着做
  • 区域定位：只做本地，还是接全国邮寄
这一节做的是暂定假设。学员此刻还不知道各品类的鉴定难度（第五站）和出货难度（第九站），现在锁死必然选错。结营前会带着后九站的信息回来重填。

1.8 前 30 天你会遇到什么

  • 真实节奏：前两周大概率没单、发的东西没反馈、加的人不回消息
  • 会遇到的四件事：同行套价、客户放鸽子、报价被嫌低、第一次看走眼
  • 什么时候该坚持、什么时候该换打法：三个可量化的判断口径
  • 不同路径的第一单通常在第几天来——预期要分路径给

二

获客五条路并排讲，选一条 all in重点交付

五条路径全部讲到能独立跑通，一条都不省。但不是让每个人都全做——第一站盘出来的那三张牌，决定你 all in 哪一条。短视频是内容路径里的一支，是主流，不是默认答案。

2.1 五条路径与 all in 逻辑 新增

路径全景

路径适合谁启动成本见效天花板稳定性
关系路径有人脉、有职业身份、有行业关系、有老客户几乎为零最快中最高
内容路径愿意出镜，或身边有人能出镜，有时间产出低慢最高低（依赖平台）
付费路径有预算、要速度、承接能力已经跑通高最快高中（花钱就有）
本地路径有门店、有本地资源、跑得动腿中中中（受区域限）高
平台路径会写文案、有耐心、想零成本起步几乎为零中中中

怎么选

  • 把第一站校验过的三张牌摊开，对着上表选，牌在哪条路上，就走哪条路
  • 三个否决项：这条路你有没有时间、有没有钱、能不能坚持三个月
  • 选不出来怎么办：默认走关系路径起步，因为它最快见到第一单，第一单能救活很多人的信心

all in 是什么意思，不是什么意思

  • 是：第一个月 80% 的时间和预算压在这一条上，把它跑到有数据可分析
  • 不是：其他四条永不碰。承接、转化、私域这些公共动作，无论走哪条路都要做
  • 什么时候该加第二条路：第一条跑出稳定数据、且已经出现瓶颈信号
  • 什么时候该换路：三个可量化的止损口径，别拿"再坚持一下"骗自己
  • 为什么不要一上来五条全铺：每条路都有学习成本和冷启动期，五条同时冷启动等于五条都启动不了
这一节是第二站的分流器，也是整门课核心主张的落点。讲完它，学员应该能当场说出："我走 X 路径，因为我手上有 Y，我第一个月的动作是 Z。"说不出来的，退回第一站重盘。

2.2 关系路径 主讲

最快出单、成本最低、唯一不依赖平台的一条路。手上有牌的人，第一个月的正确动作是把这些牌跑一遍，而不是从零开始攒粉丝。

2.2.1 存量激活

  • 通讯录与微信好友：第一条群发怎么写、发给谁、什么时间发、发几轮
  • 朋友圈铺垫：正式开口前的两周该发什么
  • 亲友第一单：怎么让第一单不欠人情、价怎么报
  • 被拒绝、被冷处理、被误解成微商，分别怎么接
  • 老客户名单激活：做过其他生意的客户怎么转过来
  • 职业身份变现：把现在的工作圈变成货源，边界在哪
  • 已有账号改造：有粉丝的账号怎么转型不掉粉，是改造还是另起
  • 已有门店客流：现有生意的进店客户怎么顺带问一句
  • 什么资源不能碰：会消耗核心信任的、会影响本职工作的

2.2.2 异业联盟

  • 对接名单：典当行、金店、修表店、洗护店、名品折扣店、美容院、会所、房产中介、保险、二手车、婚庆、律师、财务、高端健身房、月子中心
  • 异业分层：哪些出货量大、哪些客单高、先谈哪一批
  • 第一次上门怎么开口 —— 逐字话术，当场演练
  • 分成比例怎么谈、怎么结算、要不要签协议
  • 给合作方什么物料：台卡、二维码、宣传单、样品册
  • 长期怎么维护、怎么防止被跳单
  • 从单点合作到联盟网络：怎么滚到二十家

2.2.3 圈层渗透

  • 商会、老乡会、车友会、宝妈群、业主群、健身房、宠物群、兴趣圈
  • 进圈的方式：先做人再做生意，多久才能开口
  • 在群里怎么被记住又不惹人烦
  • 线下活动与聚会的转化动作

2.2.4 同行与上下游转介

  • 同行为什么会给你客户：吃不下的货、不做的品类、异地的单

五

鉴定目标不是成为鉴定师，是把损失降到最低重点交付

这一站的命题是怎么让自己不亏，不是怎么显得专业。做到这件事有两条路：自己判，和借力判。对多数人来说，借力才是主路，自己判是长期能力。所以这一站先讲兜底，再讲判定。

5.1 三道防线

  • 第一道 · 结构性规避：根本不承担真假风险——撮合、寄卖、定金后验、验货后付
  • 第二道 · 借力判定：上游兜底、机构送检、同行复核、平台鉴定
  • 第三道 · 自己判定：L1 一眼假 → L2 常见款判定 → L3 边界识别
  • 三道防线的成本、时效和适用场景对比
  • 一单看走眼等于白干多少单 —— 用第一站的测算表算给学员看
  • 三道防线分别对应第一站安全通道的哪个阶段
这一站最重要的一句话：判不了的时候知道自己判不了，然后知道该找谁。这既保护学员，也保护课程——招生时讲清楚能力边界，后面不会有人拿"我学完还是看走眼了"来找你。

5.2 外部兜底体系 新增 · 前置

上游兜底

  • 什么叫上游兜底：上游收你的货，同时替你承担判定责任
  • 上游是谁：大回收商、渠道商、B 端平台、批发档口、同行大户
  • 怎么找上游、第一次怎么开口、怎么从小单做到大单
  • 上游凭什么给你兜底：他赚什么、你让什么
  • 兜底的几种形式：先验后款、包退包换、代验代收、直接报价收
  • 成本核算：让出多少利润换兜底是合理的
  • 风险：上游压价、上游跑路、被上游挖走客户、被上游反向套价
  • 什么阶段该依赖上游、什么阶段该自己上

第三方鉴定机构

  • 得物、优奢易拍、中检、包大师：价格、时效、准确度、支持品类对比
  • 线上鉴定 vs 线下送检，各自适用什么场景
  • 出具报告的意义：对客户、对下游、对纠纷
  • 鉴定费谁出：怎么跟客户谈，怎么把它变成信任加分项
  • 机构也会看错：报告的责任边界在哪

同行复核网络

  • 怎么建：找谁、怎么开口、给不给钱、怎么互惠
  • 什么货值得麻烦别人
  • 复核的时效问题：客户等不了怎么办

结构性规避

  • 居间撮合：让买家自己去验，你只赚服务费
  • 寄卖代卖：不买断就不承担真假风险
  • 走平台交易，让平台承担鉴定责任
  • 先付定金后验货、验货后付款的具体操作

决策表：这货该怎么处理

情况处理方式
低价、常见款、自己主打品类、有小票保卡自己判，直接收

这张表是这一站的核心交付物之一，也是最能打消新手顾虑的一页。把它放进招生页——"不会鉴定也能开始，因为你有五种处理方式"，比"我教你鉴定"更能说服人。

5.3 通用判定动线

  • 拿到一件货的固定检查顺序：第 1 步看什么、第 2 步看什么，不靠灵感靠流程
  • 五个通用维度：工艺、材质、五金、字体与钢印、气味与手感

  • 高仿的档次分级：普通货、精仿、顶级复刻，各自能骗过谁
  • 为什么"感觉不对"值得信任，以及什么时候不能只靠感觉
堆细节堆不完，学员也记不住。不按品牌堆知识点，按判定动线讲——每个品类一张动线卡，回去照着走。动线卡是这一站最有价值的交付物。

估价与报价敢报、报得准、守得住

和鉴定一样，估价也有借力的路。估不准不等于不能做——上游报价、同行群、平台估价都能兜底。但长期一直用别人的价，自己永远建不起判断，所以这一站两条线并讲。

6.1 估价的外部依托 新增

  • 上游报价倒推：直接问上游这货能收多少，减掉自己的利润就是报价上限
  • 同行报价群：怎么问、怎么甄别水分、怎么不暴露自己的客户
  • 平台估价：各回收平台的在线估价工具，准不准、怎么用
  • B 端平台批量报价：适合什么货
  • 什么时候该用别人的价、什么时候必须自己算
  • 长期风险：一直依赖外部报价，利润会被上游锁死，且永远建不起自己的判断
  • 从依赖到独立的过渡路径：先对答案，再自己报，最后只在疑难件上问

6.2 估价的三个变量

  • 公价与市场行情价的区别
  • 成色分级：全新 / 99 新 / 95 新 / 九成 / 八成，各级的判定标准（接第五站）
  • 配件齐全度：包装、票据、保卡、防尘袋、多余扣，分别值多少钱
  • 瑕疵怎么折价：磨损、变形、掉色、异味、修复痕迹

6.3 行情从哪来

  • 得物、红布林、只二、心上、胖虎的成交价怎么看，看的是挂价还是成交价
  • 二奢查价小程序与工具
  • 拍卖行与批发档口的价格参考
  • 建自己的行情表，每周更新一次
  • 行情波动的信号：什么时候该压价、什么时候该抢货

6.4 折价逻辑

  • 从零售价到回收价，中间扣掉的每一层分别是什么
  • 品类系数、成色系数、配件系数、稀缺款溢价
  • 流通速度直接影响报价：好出的货可以让利抢单，难出的货必须压价
  • 留多少利润给自己，留多少空间给下游渠道
  • 走兜底渠道的货，成本里要多算哪几项

6.5 分品类估价实操

  • 包：爱马仕、香奈儿、LV、迪奥、Gucci —— 热门款与冷门款差多少
  • 表：劳力士、欧米茄、卡地亚 —— 公价、行情、有无保卡的差价
  • 黄金珠宝：金价、工费、钻石证书、回收折算方式
  • 其他品类：服饰、潮牌、数码、箱包配饰

课堂动作 · 盲报

  • 先用第五站判定过的实物报一轮，鉴定结论直接接进估价
  • 再摆二十件真货，每人独立盲报，对答案、讲差在哪
  • 评分口径：考折价逻辑和敢不敢报

6.6 报价策略

  • 先看货还是先报价
  • 区间报价怎么留口子，留多少
  • 二次压价怎么给客户一个能下台的理由
  • 什么时候该果断放弃这一单
  • 报价前先过一遍出货预判（第七站 7.1 的三问）

6.7 议价攻防 · 全场对练

每个场景两人一组对练，全程录像回放。每一场都必须先说出自己的鉴定结论和估价依据——说不出依据的，退回 6.4 重来。

  • 我再想想 / 我跟家里商量一下

  • 你靠谱吗，是不是骗子

  • 怎么告诉客户他的货是假的（与 5.11 联动）

七

成交流程标准化，一步都不能省

谈好价不等于成交。这一站把从验货到交付的每一步固化成流程，让学员不靠记性靠清单。

7.1 收货流程 SOP

  • 验货 → 出货预判 → 报价 → 议价 → 确认 → 收款 → 单据 → 交付，每一步的动作和话术
  • 现金、转账、对公，分别用在什么场景
  • 什么情况必须当场拒收，不管价格多诱人
  • 收货现场的记录规范：录什么、拍什么、存哪

出货预判三问

  • 这货走哪个渠道出
  • 预计多少天能出掉
  • 扣完手续费物流之后，到手价是多少

八

风控前面赚的钱，都可能在这里赔回去重点交付

集中处理合同、税务、平台、用人、资金、人身安全六类风险。不只讲怎么防，更讲防不住会怎样——新手不重视登记和合同，多半是因为没人告诉过他最坏情况长什么样。

风控放在成交之后、出货之前是刻意的。放第一站太早，学员没收过货，挂不住；放最后又太晚，制度得在规模起来之前建好。这个位置上，合同、登记、存证每一条都有具体的挂靠对象，而学员还没大规模出货和用人，来得及。

8.1 风险总表

  • 把散在前七站的红线汇总成一张表：什么绝对不做、什么必须做
  • 六类风险的严重度排序：哪些会亏钱、哪些会封号、哪些会摊上官司
  • 每一条对应的自查动作与频率

8.2 货品来源风险

  • 赃物：怎么识别、身份登记怎么做、来源怎么问
  • 收到赃物的实际后果：货怎么处理、钱能不能追回、自己要担什么责任
  • 抵押货、法拍物、公司资产货、离婚财产纠纷货
  • 代卖货：卖家不是所有人的情况怎么办
  • 未成年人、限制民事行为能力人卖货
  • 旧货经营的登记与备案要求（按当地规定核实）

8.3 合同与协议体系

  • 回收协议：关键条款、真假争议条款、反悔条款
  • 寄卖协议：责任划分、丢损赔偿、期限与降价授权
  • 代收 / 撮合协议：三方关系怎么写清
  • 异业合作协议：分成、结算、跳单条款、保密
  • 上游合作协议：兜底范围、退换条件、结算方式、争议处理
  • 出镜人合作协议 新增：报酬、账号与素材归属、肖像授权、退出交接、竞业约定
  • 员工协议：劳动合同、保密协议、竞业限制、货品交接责任
  • 合伙协议：出资、分工、分成、退出机制
  • 每份协议逐条讲关键点和常见坑，现场填自己的信息
  • 什么情况必须签、什么情况口头也行、签了怎么保管

8.4 登记、存证与档案

  • 身份证登记规范：登记什么、怎么存、隐私边界在哪
  • 全程录像规范：什么时候开、录多久、存多久
  • 货品拍照存档：拍哪几张、什么角度、怎么归档
  • 聊天记录与转账凭证的保存
  • 出了纠纷，哪些证据能用、哪些不能用
  • 档案怎么建，一单一档还是按月归集

8.5 交易与资金风险

  • 先款先货的原则：什么情况绝对不能先发货
  • 账期风险：给同行、给平台、给上游，各自的账期怎么控
  • 大额转账与到账确认，假转账截图的识别
  • 假币与验钞
  • 常见诈骗套路：调包、假货换真货、冒充买家、假鉴定报告、异地邮寄骗局
  • 客户事后反悔、恶意退货、投诉纠纷怎么处理
  • 第三方担保与平台交易的使用时机

8.6 税务与经营合规

  • 个体户还是公司，什么阶段该注册，各自的税负差异
  • 经营范围怎么写，旧货经营需要什么资质
  • 三本账：进货台账、销售台账、库存台账，怎么记、谁来记
  • 进项凭证的难题：从个人手里收货没有发票怎么办
  • 销项与开票：什么情况客户会要发票，怎么应对
  • 私账公账分开，为什么必须分
  • 个人账户大额流水的风险
  • 什么阶段该找代账、找什么样的

8.7 平台与内容风险

  • 违禁词深化：平台规则的更新节奏，怎么自己查最新规则
  • 虚假宣传风险："保真""正品保证""最高价""行业第一"这类表述的法律与平台风险
  • 素材侵权：品牌图、他人视频、背景音乐的使用边界
  • 客户隐私：拍客户、拍身份证、发成交实拍的边界与授权
  • 价格承诺与实际报价不符引发的投诉
  • 投放合规：付费投放的素材审核与行业资质要求

  • 账号资产保全：多平台备份、私域沉淀、素材本地存档

出镜人与合伙人 新增

9.1 出货渠道全景

  • 得物：寄卖与回收两条路、鉴别流程、手续费、账期、什么货适合走

  • 直播间寄卖：怎么找主播、怎么分成、什么货在直播间走得动
  • B 端平台：批量出货怎么走、报价怎么谈
  • 自己零售：闲鱼、转转、朋友圈、小红书、抖音小店、门店，利润最高但最慢

  • 真假存疑的货怎么处理，绝对不能往哪里出
  • 一张对照表：货品特征 → 首选渠道 → 备选渠道 → 预计天数 → 到手价

9.3 上游与同行渠道怎么搭

  • 怎么进圈、找谁、第一次怎么开口
  • 建立信任的过程：先小单后大单，先验后款
  • 账期与风控：什么情况下绝对不能先发货
  • 长期合作的分成与互相调货
  • 同行群的规矩与黑话
  • 把上游从"兜底方"发展成"稳定出口"

9.4 定价与利润分配

  • 出货定价怎么定，留多少议价空间
  • 各渠道的实际到手价怎么算：扣完手续费、物流、鉴定费之后还剩多少
  • 同一件货在不同渠道的到手价对比实操

9.5 零售端的运营

  • 买家的疑虑怎么打消：验货、退换、保真承诺的边界（呼应 8.7）
  • 售后与退货处理

9.6 库存与资金周转

  • 周转天数怎么算，多少天算健康
  • 滞销预警：超过多少天必须降价出手
  • 已经压货了怎么办：降价、换渠道、拆件、同行调换、打包甩

  • 从客户里挑线人和合伙人

人群路径导航

凡是有获客需求、或有二手成交意向的人都能学。开课第一天发这张表，帮学员对上自己该 all in 哪条路。

有人脉、有职业身份、有行业关系、有老客户
→ 关系路径。第一站的资源盘点是你最重要的一节课。你的第一单大概率来自现有关系，不是平台。别把现成的牌扔了去从零起号。第五站重点听 5.2 兜底体系——你有客户但缺专业，正好用兜底补上。
没资源，但愿意出镜、有时间产出
→ 内容路径。天花板最高但最慢，前两周没反馈是正常的。第五站和第六站必须扎实，因为你的信任全靠专业度建立，没有熟人背书兜底。
没资源、也不愿出镜，但身边有人能出镜
→ 内容路径，重点听 2.3.4 出镜分工，以及第八站的出镜人风险。分工和协议先谈清楚，再开始拍。
有预算、想快
→ 付费路径。但前提是承接和转化已经跑通，否则投进去的钱全漏掉。第三、四站要先啃，第二站的付费部分反而简单。
有门店、有本地资源、跑得动腿
→ 本地路径。地图、点评、地推是你的主场，区域做透了比什么都稳。短视频做同城内容作为补充即可。
什么都没有，只有时间和耐心
→ 平台路径。闲鱼零成本、不用露脸、不用人脉，是资源最少的人唯一能立刻开始的一条路。
已入行缺客源
用第十站的六个数找出自己掉率最高的环节，回去先补那一站。第二站按自己现有资源重新选一次路——很多人卡住是因为选错了路，不是不够努力。
已入行怕看走眼
第五站的 5.1 三道防线和 5.2 兜底体系是你来的理由，第八站风控必听。回去先把上游、复核关系和存证规范建起来，再谈扩量。
老学员回炉
开课前做三个自测：第五站的实物盲测与决策表判断、第六站的盲报、第九站的分渠道。哪一站掉分最多，时间就压在哪一站。
带团队的学员
正课按单兵内容学，第八站的用人与合作风险必听。团队复制走结营后的选修加餐。

与技术课的衔接

  • 能力切分：本课交付三道防线的全部内容——结构性规避、外部兜底、以及自己判定的 L1 一眼假 / L2 常见款 / L3 边界识别。技术课接 L3 之后：疑难件、全品类深度、鉴定服务变现。
  • 盲测考什么：考动线走得对不对、判断敢不敢下、边界认得清不清、决策表用得准不准。不是考记住了多少细节点。
  • 招生页必须写清：这门课让你会什么（五条获客路径、承接转化、避损体系与常见款鉴定、估价报价、风险防控、出货复购），不会什么（疑难件与全品类深度鉴定）。含糊过去的话，退款和差评的风险都在这里。
  • 样本库要求：第五站的实物盲测需要真货与不同档次的高仿样本。品类覆盖和高仿档次直接决定这一站的交付质量，是筹备期的第一优先级。
  • 兜底资源要求：5.2 要交付的不只是方法，还有可对接的上游和机构清单。这部分是你的独家资源，也是这门课最难被抄走的地方。
